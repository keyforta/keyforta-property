# WEB-004 featured listing intro overflow

## Authority

- Approved issue: https://github.com/keyforta/keyforta-property/issues/2
- Task contract: `harness/tasks/WEB-004.json`
- Assigned route: `ROUTE-004`

## Failure evidence

On the French public homepage, the featured-listing introduction extends across
the listing cards and beyond the right viewport edge. The supplied desktop
screenshot reproduces the defect with this existing localized copy:
`Explorez les annonces avec disponibilite, indices de verification, conditions
locatives et demandes de visite.`

The controlling desktop rule in `apps/public-web/src/styles.css` applies
`white-space: nowrap` to the featured-section introduction. The sentence is
longer than the horizontal space remaining beside the section heading, so the
browser cannot wrap it inside its 760 px maximum width.

## Scope

Remove the forced single-line behavior from the featured introduction while
preserving its copy, maximum width, section structure, cards, and responsive
breakpoints. Add a focused source check that rejects a future `nowrap` rule on
the featured introduction.

The affected product invariant is responsive readability: localized text must
remain inside its parent section at supported desktop and mobile widths.

## Verification plan

- Run `pnpm --filter @keyforta/public-web check` for the focused regression.
- Run `pnpm --filter @keyforta/public-web build` for production compilation.
- Inspect the French homepage at desktop and mobile widths for wrapping and
  horizontal overflow.
- Run `pnpm verify` for canonical repository verification.

## Implementation

- Kept the existing 760 px maximum width for the featured introduction.
- Removed the featured introduction from the desktop `white-space: nowrap`
  behavior while preserving that behavior for the unrelated process section.
- Added a static regression assertion that rejects `white-space: nowrap` in the
  featured introduction rule.

## Results

`pnpm --filter @keyforta/public-web check` passes the focused regression and
`pnpm --filter @keyforta/public-web build` completes successfully. Vite reports
its existing advisory that the main bundle exceeds 500 kB; the build does not
fail.

Rendered French-homepage measurements confirm:

- At 1350 x 768, the introduction uses `white-space: normal`, wraps to two
  lines, and its right edge equals the section's right edge at 1318 px.
- At 390 x 844, the introduction uses `white-space: normal`, wraps to three
  lines, and remains between the section edges at 12 px and 378 px.
- At both widths, document `scrollWidth` equals `clientWidth`, confirming no
  horizontal page overflow.

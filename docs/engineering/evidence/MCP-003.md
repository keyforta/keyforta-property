## Business invariant

The widget and its model-hidden metadata cannot establish actor or organization
authority, receive credentials, call the private API, or expose tenant data.

## Implementation plan

1. Add a small versioned widget bridge that validates source, exact origin,
   protocol version, message kind, and payload before dispatch.
2. Add shared deterministic Vite configuration for standalone widget HTML.
3. Build the synthetic health widget with typed English and French strings and
   loading, empty, populated, and error states.
4. Add bridge, state, accessibility, localization fallback, and standalone
   build tests.
5. Run focused package checks, dependency audit, and canonical verification.

## Acceptance-test map

| Criterion | Verification |

| `AC-MCP-003-01` | Widget tests cover loading, empty, populated, and safe error states in English and French. |

| `AC-MCP-003-03` | Build test verifies deterministic standalone `dist/index.html` with no unrestricted network origin. |

## Dependency boundary

Use the repository's React 19, Fluent UI 9, Vite 7, and TypeScript 5 versions.
New test dependencies must be pinned, audited, and local to the owning packages.

## Exclusions

client, model provider, public ingress, infrastructure, credentials, paid
service, or deployment is included.

## Rollback

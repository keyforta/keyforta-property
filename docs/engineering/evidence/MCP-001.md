## Business invariant

The model, connector, tool input, widget, and `_meta` channel cannot establish
actor or organization authority, receive credentials, or bypass application
authorization. This scaffold exposes no tenant data and changes no deterministic
product workflow.

## Bounded implementation plan

1. Add root TypeScript and Turbo configuration while preserving direct pnpm
   package scripts and uncached canonical harness verification.
2. Add `packages/types` with dependency-free type-only MCP and widget bridge
   declarations.
3. Add strict runtime schemas to `packages/contracts` for safe errors, widget
   resources, execution context, bridge messages, and dual-layer tool results.
4. Add tests for valid contracts, unknown-key rejection, prohibited security
   fields, resource URI shape, message versions, and 1024-byte description
   enforcement.
5. Run package checks, Turbo checks, dependency audit, and canonical
   verification.

## Acceptance-test map

| Criterion | Verification |
| --- | --- |
| `AC-MCP-001-01` | Type package emits declarations, imports with no runtime dependency, and preserves JSON-serializable contract shapes. |
| `AC-MCP-001-02` | Runtime schemas accept exact valid results and reject unknown keys, invalid resource URIs, invalid bridge versions, and descriptions at or above 1024 UTF-8 bytes. |
| `AC-MCP-001-03` | Recursive forbidden-field tests reject tokens, credentials, secrets, cookies, authorization context, and client-supplied actor or organization authority in model and widget channels. |

## Package boundary

`@keyforta/types` contains erased TypeScript declarations only. Runtime Zod
schemas remain in `@keyforta/contracts`. Neither package imports application
code, React, Fastify, Azure, model-provider SDKs, database clients, or UI
implementations.

## Dependency impact

The proposal adds pinned Turbo and TypeScript root development dependencies and
uses the existing Zod dependency in `@keyforta/contracts`. No MCP SDK, React,
Fluent UI, Vite, Storybook, OAuth, provider, Azure, or database dependency is
included in this slice.

## Security checks

- Strict object schemas reject unknown fields at every boundary.
- `ToolExecutionContext` carries a validated principal reference and scopes,
  never a raw bearer token.
- `_meta` remains widget-visible and receives the same prohibited-field scan as
  model-visible content.
- Safe errors expose only stable code, localization key, retryability, and
  correlation ID.
- Widget messages use explicit protocol versions and discriminated message
  kinds; runtime source/origin checks belong to the later `ui-core` task.

## Exclusions

No server endpoint, authentication middleware, tool handler, React widget,
Storybook, Vite build, infrastructure, identity registration, public ingress,
external credential, provider call, business data, or deployment is included.

## Rollback

Remove the new type package and MCP schema exports, remove Turbo and the shared
TypeScript config, restore the prior root scripts and workspace globs, and
regenerate the lockfile. No data or remote resource requires rollback.

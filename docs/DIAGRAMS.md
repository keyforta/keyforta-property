# Diagram catalog

This catalog inventories Mermaid diagrams in `docs/`. A diagram's status says
how it may be used; it does not claim that a depicted service or capability is
deployed. The linked authoritative source controls when a supporting view
differs from a contract, ADR, migration, manifest, or workflow.

## Status vocabulary

- **Implemented:** describes repository behavior evidenced by current source.
- **Normative target:** visualizes an authoritative contract, including work
  that may not yet be implemented.
- **Supporting:** explains authoritative material but does not replace it.
- **Proposed:** records a proposal that still requires approval.
- **Historical:** preserves superseded context and is not current direction.

## Ownership and review

The semantic owner reviews meaning and scope; maintainers of a trigger path
review structural accuracy when that path changes. A change to normative
behavior belongs in its authoritative contract first. Add, remove, or rename a
catalog entry in the same change that adds, removes, or renames a Mermaid block.

## Syntax verification

`pnpm check:diagrams` uses the exact Mermaid version pinned in `package.json` to
parse every Mermaid block under `docs/**`; `pnpm verify` runs that check locally
and in CI. Passing the check proves parseability only. Each semantic owner
remains responsible for the diagram's factual accuracy, authority, status, and
timely review.
